Babelfish for PostgreSQL 现已支持 PostgreSQL 16。详细改进列表见[发行说明](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/releases/tag/BABEL_4_0_0__PG_16_1)。

同时发布的还有兼容 PostgreSQL 15.5 的 [Babelfish 3.4.0](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/releases/tag/BABEL_3_4_0__PG_15_5)，以及兼容 PostgreSQL 14.10 的 [Babelfish 2.7.0](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/releases/tag/BABEL_2_7_0__PG_14_10)。

感谢你一直以来对项目的支持与参与！
