> [!NOTE] 历史公告
> 本文保留原始发布日期、作者及版本语境。中文翻译：PGSTY 文档项目。

Babelfish for PostgreSQL 开源项目已经走过两年，我们将对项目的组织和运作做出一些调整。首先，感谢众多开发者下载、使用 Babelfish，并报告问题、提出改进建议。尤其感谢那些提交修复和增强功能、且已合入代码库的社区成员。没有社区的诸多贡献，项目不会有今天的样子。

Babelfish 由社区驱动。本次调整旨在更及时地向社区传递变化，鼓励成员积极参与改进，扩大项目的影响力并推动其发展。

首先，文档和发行说明将迁往 GitHub，以便维护并保持更新。

- 最新文档请访问 [GitHub Wiki](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/wiki/)。
- 与其他开源项目一样，发行说明将随各个版本一起发布，见 [GitHub Releases](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/releases)。

网站内容仍在迁移中。由于项目持续增加功能、修复问题并更新使用说明，原网站内容很难保持及时、准确，我们将移除其中大部分现有文档。

其次，将开放 [GitHub Discussions](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/discussions)。除了提交 issue，社区成员还可以在这里问答、交流开放性话题，了解影响当前项目和未来路线图的决策。我们也会在此讨论技术设计，希望社区成员在各个层面参与，无论贡献大小，共同改进设计和最终产品。选择这一论坛，是为了支持社区参与和进步，并建立项目成功所需的透明度、信任与投入。

第三，将通过 GitHub Issues 邀请社区处理开放问题，把贡献反馈给开源项目。我们会把大部分内部跟踪的问题移到 GitHub，并标记为 `up-for-grabs` 或 `help wanted`。任何社区成员都可以认领并提交 PR。其中会包含适合初学者的问题（原文称为 “first good issue” 标签），也会有不少棘手的问题。PR 完成审阅后，由项目提交者合入代码库。

感谢你一直以来对项目的支持与参与！
