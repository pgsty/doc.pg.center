Download Babelfish source bundles from [GitHub Releases](https://github.com/babelfish-for-postgresql/babelfish-for-postgresql/releases). Each bundle contains an `INSTALLING.md` with build instructions and dependencies for that version.

> [!TIP] Build from the release instructions
> The [website's source installation page](/babelfish/installation/compiling-babelfish-from-source/) describes Ubuntu 20.04. Other platforms and newer releases may differ; follow the instructions included with your chosen bundle.
