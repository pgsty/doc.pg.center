Babelfish for PostgreSQL and the extensions and tools included in the project are open source. The upstream project documents the Babelfish components under the Apache 2.0 and PostgreSQL licenses.

The following repositories make up the project:

- [Babelfish Patch](https://github.com/babelfish-for-postgresql/postgresql_modified_for_babelfish) — protocol hooks patch for PostgreSQL.
- [Babelfish Extensions](https://github.com/babelfish-for-postgresql/babelfish_extensions) — TDS and T-SQL extensions and tests.
- [Babelfish Compass](https://github.com/babelfish-for-postgresql/babelfish_compass) — compatibility assessment tooling.
- [Babelfish Website](https://github.com/babelfish-for-postgresql/babelfish_project_website) — upstream website source.
- [PostgreSQL](https://github.com/postgres/postgres) — the database project.
- [Fixed Decimal](https://github.com/2ndQuadrant/fixeddecimal) — the fixed-decimal extension used for the money type.

[Extension contribution guide](https://github.com/babelfish-for-postgresql/babelfish_extensions/blob/BABEL_1_0_0/CONTRIBUTING.md) (historical version linked by the upstream website).
