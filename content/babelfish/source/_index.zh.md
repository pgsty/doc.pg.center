Babelfish for PostgreSQL 以及项目中包含的扩展和工具都是开源软件。上游项目说明，Babelfish 组件采用 Apache 2.0 与 PostgreSQL 双许可证。

项目由以下仓库组成：

- [Babelfish Patch](https://github.com/babelfish-for-postgresql/postgresql_modified_for_babelfish)：PostgreSQL 协议钩子补丁。
- [Babelfish Extensions](https://github.com/babelfish-for-postgresql/babelfish_extensions)：TDS、T-SQL 扩展与测试。
- [Babelfish Compass](https://github.com/babelfish-for-postgresql/babelfish_compass)：兼容性评估工具。
- [Babelfish Website](https://github.com/babelfish-for-postgresql/babelfish_project_website)：上游网站源码。
- [PostgreSQL](https://github.com/postgres/postgres)：数据库项目。
- [Fixed Decimal](https://github.com/2ndQuadrant/fixeddecimal)：money 类型使用的定点小数扩展。

[扩展贡献说明](https://github.com/babelfish-for-postgresql/babelfish_extensions/blob/BABEL_1_0_0/CONTRIBUTING.md)（上游网站引用的历史版本）。
