Diese Einträge geben den vollständigen Upstream-Änderungsverlauf für
pgBadger 12.x wieder, beginnend mit der neuesten Version.

## v12.4 · 2023-12-25 {#v12-4}

Dieses Wartungsrelease von pgBadger behebt Probleme, die Benutzer seit dem
letzten Release gemeldet haben.

  - Korrigiert den PgBouncer-Bericht für Version 1.21. Dank an Ales Zeleny für
    den Patch.
  - Verhindert, dass die Parallelität pro Datei die Anzahl der Dateien
    übersteigt. Dank an maliangzhu für die Meldung.
  - Behebt den seit v12.3 fehlerhaften Regressionstest. Dank an ieshin für die
    Meldung.
  - Korrigiert Fälle, in denen Einträge der Ebene LOG als Einträge der Ebene
    ERROR gezählt wurden. Dank an Matti Linnanvuori für die Meldung.

## v12.3 · 2023-11-27 {#v12-3}

Dieses Wartungsrelease von pgBadger behebt Probleme, die Benutzer seit dem
letzten Release gemeldet haben. Es fügt außerdem einige neue Funktionen hinzu:

  * Fügt die Option --include-pid hinzu, um ausschließlich Ereignisse einer
    Sitzung mit der PID (%p) zu melden. Die Option kann mehrfach verwendet
    werden. Dank an Henrietta Dombrovskaya für den Funktionswunsch.
  * Fügt die Option --include-session hinzu, um ausschließlich Ereignisse mit
    der Sitzungs-ID (%c) zu melden. Die Option kann mehrfach verwendet werden.
    Dank an Henrietta Dombrovskaya für den Funktionswunsch.
  * Fügt die neue Option --dump-raw-csv hinzu, die lediglich das Protokoll parst
    und die Informationen im CSV-Format ausgibt. Es erfolgt keine weitere
    Verarbeitung und es wird kein Bericht erzeugt. Dank an Henrietta
    Dombrovskaya für den Funktionswunsch.

Vollständige Liste der Änderungen und Danksagungen:

  - Aktualisiert pgFormatter auf Version 5.5.
  - Korrigiert das Enddatum beim Parsen des jsonlog-Formats. Dank an jw1u1 für
    die Meldung.
  - Korrigiert einen Tippfehler in „Sessions per application“. Dank an fairyfar
    für den Patch.
  - Behebt einen Fehler im Diagramm „INSERT/UPDATE/DELETE Traffic“. Dank an
    fairyfar für den Patch.
  - Korrigiert das Parsen verwaister Zeilen mit Bind-Abfragen. Dank an youxq für
    die Meldung.
  - Korrigiert den Bericht „Analyze per table“ für neue PG-Versionen. Dank an
    Jean-Christophe Arnu für den Patch.
  - Korrigiert den Parser für Syslog-Einträge, wenn der Syslog-Zeitstempel
    Millisekunden enthält. Dank an Pavel Rabel für die Meldung.

Dieses Wartungsrelease von pgBadger behebt Probleme, die Benutzer seit dem
letzten Release gemeldet haben. Es fügt außerdem zwei neue Funktionen hinzu:

  - Ersetzt für die Windows-Portierung Aufrufe von POSIX::strftime("%s", ....)

## v12.0 · 2022-09-13 {#v12-0}

Dieses Major-Release von pgBadger behebt einige Probleme, die Benutzer in den
vergangenen fünf Monaten gemeldet haben. Wie gewohnt enthält es außerdem neue
Funktionen und Verbesserungen:

  * Entfernt die Unterstützung der Tsung-Ausgabe.
  * Verbessert die Leistung von pgBadger, wenn Hunderte von Bind-Parametern
    ersetzt werden müssen.
  * Entfernt die Option -n | --nohighlight, die seit dem Upgrade auf pgFormatter
    4 nicht mehr verwendet wird.
  * Sendet auto_explain-Pläne per POST an explain.depesz.com, um die
    Längenbeschränkung für GET-Parameter zu umgehen.
  * Wendet --exclude-query und --include-query auf Bind-/Parse-Traces an.
  * Ergänzt die Dokumentation um einen Link zu den pgBadger-Beispielberichten.

Vollständige Liste der Änderungen und Danksagungen:

  - Korrigiert Monatsberichte, die mit „log file ... must exists“ fehlschlugen.

    wenn die Eingabe stdin ist. Dank an aleszeleny für die Meldung.
