## v9.2 · 2017-07-27 {#v9-2}

pgBadgerのこのリリースは、いくつかの新機能を追加するメンテナンスリリースです。

  * チェックポイントの距離と推定値のレポートを追加しました。
  * AWS RedshiftキーワードのサポートをSQLコード整形ツールに追加しました。
  * リモートモードでのログ形式の自動検出を追加して、pgbouncerログファイルとPostgreSQLログファイルをリモートで解析できるようにします。

いくつかのバグ修正と機能強化もあります。

  - 最後の範囲より上のデータが表示されなかったヒストグラムを含むレポートを修正しました。
  - ログ行番号パターン([%l-n])を使用しないjournalctlの解析を修正しました。報告してくださったChristian Schmittに感謝します。
  - チェックポイントの距離と推定値のレポートを追加しました。機能を要望してくださったjjsantamに感謝します。
  - CSSおよびJavaScriptファイルを更新するスクリプトtools/updt_embedded_rsc.plが実行する内容の詳細情報を追加しました。
  - すべてのログファイルが空の場合は警告を出さず、コード0で終了します。
  - %regex_mapのルックアップとして%nを含まないbuild_log_line_prefix_regex()を修正しました。パッチを提供してくださったghosthoundに感謝します。
  - 「FATAL: cannot use CSV」のエラーレベルをWARNINGに変更しました。報告してくださったkong1manに感謝します。
  - 初期化されていない値の使用に関する警告を修正しました。 報告してくださったPayalに感謝します。
  - 「permission denied」をエラー正規化に追加しました。
  - pgbadgerをpgFormatterの最新のコミット5bdc018に更新しました。
  - AWS Redshiftキーワードのサポートを追加しました。機能を要望してくださったcavanaugに感謝します。
  - クエリーがキャンセルされたときに一時ファイルレポートに欠落していたクエリーを修正しました。報告してくださったFabrizio de Royes Melloに感謝します。
  - バインドされたパラメーターを使用してクエリーを正規化し、?に置き換えました。
  - 終了時刻が開始時刻より前になることを避けるための健全性チェック。パッチを提供してくださったChristophe Courtoisに感謝します。
  - 多数の誤記と文法を修正しました。バイナリファイルではなくプログラムを指す場合は、「pgBadger」を使用します。また、PgBouncer、GitHub、CSSなどの正式な表記を使用しました。 PODファイルはREADMEと同期されました。パッチを提供してくださったEuler Taveiraに感謝します。
  - --disable-type 使用時にメニューが壊れる問題を修正しました。top_cancelled_infoテストとリストの終了部はdisable_typeテストの内側にある必要があります。ついでに、disable_lockテストのインデントを整えました。パッチを提供してくださったEuler Taveiraに感謝します。
  - 初期化されていない値の使用を修正しました。 報告してくださったjohnkruggerに感謝します。
  - ファイルがリモートでホストされている場合、ログ形式の自動検出中にログファイルを読み取るテストを削除しました。 報告してくださったclomddに感謝します。
  - リモートモードでのログ形式の自動検出を追加して、pgbouncerログファイルとPostgreSQLログファイルをリモートで解析できるようにします。
  - ログ行の検証後に誤って増加したセッション数を修正しました。報告してくださったAchilleas Mantziosに感謝します。
  - pgBadger説明の小規模な再フォーマット。
  - ドキュメント内の繰り返しの情報を修正。パッチを提供してくださったcscatoliniに感謝します。

## v9.1 · 2017-01-24 {#v9-1}

pgBadgerのこのリリースは、いくつかの新機能を追加するメンテナンスリリースです。

  * SQLStateがlog_line_prefixで利用可能な場合のエラークラス分布のレポートを追加します(%eプレースホルダーを参照)。
  * SQLビューティファイアをpgFormatter v1.6コードに更新しました。
  * エラーメッセージの正規化を改善します。
  * --normalized-only オプションを追加して、カウント付きのログ内で見つかったすべての正規化されたクエリーを含むテキストファイルを生成します。
  * 一意のセッションIDとして%c (セッションID)が%p (pid)を置き換えることを許可しました。
  * イベントレポートにロック待機メッセージを追加しました。
  * --start-monday オプションを追加して、暦週をデフォルトの日曜日ではなく月曜日から開始します。

いくつかのバグ修正と機能強化もあります。

  - SQLStateがログ行プレフィックスで使用可能な場合のエラークラス分布のレポートを追加しました。機能を要望してくださったjacks33に感謝します。

  - コマンドタグlog_line_prefixプレースホルダー%iを修正してスペース文字を許可しました。
  - --exclude-line オプションを修正し、保持期間が設定され、--noreport が使用されている場合に古いディレクトリを削除しました。
  - 「バキュームアクティビティテーブル」のタイプミスを修正。パッチを提供してくださったNicolas Golletに感謝します。

  - -fオプションにpgbouncerログ形式に関する情報を追加しました。 報告してくださったclomddに感謝します。
  - ドキュメントに --normalized-only 情報を追加しました。
  - 以前のパッチで導入された日付/時刻の壊れたレポートを修正しました。
  - log_duration=onおよびlog_statement=allの場合の実行時間とクエリーの関連付けを修正しました。報告してくださったEric Jensenに感謝します。
  - アドバイザリロックに関するメッセージの正規化を修正しました。報告してくださったThibaut Madelaineに感謝します。

  - 正規表現の停止文字に開き丸括弧を追加して、プレフィックス内のDBクライアントを検索し、ソースポートを含むPostgreSQLクライアント文字列形式を処理するようにしました。パッチを提供してくださったJon Nelsonに感謝します。

## v9.0 · 2016-09-02 {#v9-0}

pgBadgerのこのメジャーリリースは、Bootstrap 3への移植と、すべてのリソースファイル(CSSおよびJavaScript)のバージョンアップグレードです。いくつかのバグ修正と機能強化もあります。

古い増分レポートとの後方互換性が維持される場合があります。

  - リソースファイルのソースとライセンスは、専用のサブディレクトリに配置されるようになりました。 pgbadgerスクリプトに埋め込まれた縮小バージョンを更新するためのスクリプトが追加されました。ヘルプと機能リクエストを提供してくれたChristoph Bergに感謝します。

  - 接続のログ出力が有効で、log_line_prefixにユーザー・データベース・ホストが含まれていない場合は、接続文字列からuser/database/hostの検出を試みます。
    正規表現を拡張して、データベース名、ユーザー名、クライアントIPアドレス、およびアプリケーション名を自動検出します。現在の正規表現は次のとおりです。

    	db => qr/(?:db|database)=([^,]*)/;
    	user => qr/(?:user|usr)=([^,]*)/;
    	client => qr/(?:client|remote|ip|host)=([^,]*)/;
    	appname => qr/(?:app|application)=([^,]*)/;

  - 新しいCSSおよびJavascriptファイル用のサブディレクトリを作成することにより、増分モードでの古いバージョンのpgbadgerとの後方互換性を追加しました。このサブディレクトリには、pgbadgerのメジャーバージョン番号が付けられています。
  - 新しいフォントサイズでは小さすぎるpgbadgerロゴのサイズを大きくします。

  - すべてのレポートの詳細情報を正規化します。

  - ロックレポートの重複コピーアイコンを修正しました。

  - セッション時間のヒストグラムに欠落していたグラフを修正しました。報告してくださったGuillaume Lelargeに感謝します。

  - リソースファイルで使用されるライセンスを記録したLICENSEファイルを追加しました。パッチを提供してくださったChristoph Bergに感謝します。

  - jqplotライブラリにパッチを追加して、いくつかのチャートをダウンロードしようとしたときの無限ループを修正しました。この問題の解決に協力してくれたJulien Tachoiresに感謝します。
  - スクリプトtools/updt_embedded_rsc.plは、リソースファイルresources/jquery.jqplot.jsにパッチを適用しますが、すでに適用されている場合には警告を出しません。

  - 円グラフデータセットの末尾にある最後のカンマを1つ削除しました。 報告してくださったJulien Tachoiresに感謝します。

  - 正規化エラーの表示変更

  - 未使用または自動生成されたファイルを削除します

  - すべてのリソースファイル(js+css)を更新し、pgbadgerで使用されるJavaScriptライブラリのソースを含めるディレクトリを作成するようにしました。新しいスクリプトtools/updt_embedded_rsc.plもあり、これらのファイルの縮小バージョンを生成し、pgbadgerに埋め込むために使用できます。  このスクリプトは、FontAwesome.otfオープンTrueTypeフォントをfontawesome.cssファイルに埋め込みます。
