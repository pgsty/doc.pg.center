これらのエントリは、pgBadger 9.x の完全なアップストリーム変更レコードを最新のものから順に保存します。

## v9.2 · 2017-07-27 {#v9-2}

pgBadger のこのリリースは、いくつかの新機能を追加するメンテナンス リリースです。

  * チェックポイントの距離と推定値のレポートを追加します。
  * AWS Redshift キーワードのサポートを SQL コード整形ツールに追加します。
  * リモート モードでのログ形式の自動検出を追加して、pgbouncer ログ ファイルと PostgreSQL ログ ファイルをリモートで解析できるようにします。

いくつかのバグ修正と機能強化もあります。

  - 最後の範囲より上のデータが表示されなかったヒストグラムを含むレポートを修正しました。
  - ログ行番号パターン ([%l-n]) を使用しないjournalctlの解析を修正しました。レポートを提供してくれた Christian Schmitt に感謝します。
  - チェックポイントの距離と推定値のレポートを追加します。機能リクエストをくださった jjsantam に感謝します。
  - CSS および JavaScript ファイル tools/updt_embedded_rsc.pl. を更新するスクリプトによって実行される内容の詳細を追加します。
  - すべてのログ ファイルが空の場合は警告を出さず、コード 0 で終了します。
  - %regex_map のルックアップとして %n を含まない build_log_line_prefix_regex() を修正しました。パッチを提供してくれた Ghosthound に感謝します。
  - 「FATAL: cannot use CSV」のエラーレベルをWARNINGに変更しました。報告してくださったkong1manに感謝します。
  - 初期化されていない値の使用に関する警告を修正しました。 Payal さん、レポートありがとうございます。
  - エラー正規化への追加権限が拒否されました
  - pgbadger を pgFormatter の最新のコミット 5bdc018 に更新します。
  - AWS Redshift キーワードのサポートを追加します。機能リクエストをくださった cavanaug に感謝します。
  - クエリがキャンセルされたときに一時ファイル レポートに欠落していたクエリを修正しました。レポートを提供してくれた Fabrizio de Royes Mello に感謝します。
  - バインドされたパラメータを使用してクエリを正規化し、? に置き換えます。
  - 終了時刻が開始時刻より前になることを避けるための健全性チェック。パッチを提供してくれた Christophe Courtois に感謝します。
  - 多くのミスタイプの単語を修正し、文法的な修正を行います。バイナリ ファイルではなくプログラムを指す場合は、「pgBadger」を使用します。また、PgBouncer、GitHub、CSS などの "official" 式を使用します。 POD ファイルは README と同期されました。パッチを提供してくれた Euler Taveira に感謝します。
  - --disable-type top_canceled_info テストと終了リストが disable_type テスト内にある必要がある場合、Menu が壊れます。その中に、disable_lock テストを識別します。パッチを提供してくれた Euler Taveira に感謝します。
  - 初期化されていない値の使用を修正しました。 johnkrugger さん、レポートありがとうございます。
  - ファイルがリモートでホストされている場合、ログ形式の自動検出中にログ ファイルを読み取るテストを削除します。 clomdd さん、レポートありがとうございます。
  - リモート モードでのログ形式の自動検出を追加して、pgbouncer ログ ファイルと PostgreSQL ログ ファイルをリモートで解析できるようにします。
  - ログ行の検証後に誤って増加したセッション数を修正しました。Achilleas Mantzios のレポートに感謝します。
  - pgBadger 説明の小規模な再フォーマット。
  - ドキュメント内の繰り返しの情報を修正。パッチを提供してくれた cscatolini に感謝します。

## v9.1 · 2017-01-24 {#v9-1}

pgBadger のこのリリースは、いくつかの新機能を追加するメンテナンス リリースです。

  * SQLState が log_line_prefix で利用可能な場合のエラー クラス分布のレポートを追加します (%e プレースホルダーを参照)。
  * SQL ビューティファイアを pgFormatter v1.6 コードに更新します。
  * エラー メッセージの正規化を改善します。
  * --normalized-only オプションを追加して、カウント付きのログ内で見つかったすべての正規化されたクエリを含むテキスト ファイルを生成します。
  * 一意のセッション ID として %c (セッション ID) が %p (pid) を置き換えることを許可します。
  * イベント レポートにロック待機メッセージを追加します。
  * --start-monday オプションを追加して、暦週をデフォルトの日曜日ではなく月曜日から開始します。

いくつかのバグ修正と機能強化もあります。

  - SQLState がログ行プレフィックスで使用可能な場合のエラー クラス分布のレポートを追加します。機能リクエストをくださった jacks33 に感謝します。
  - サイズ変更時の増分グローバル インデックスを修正しました。 clomdd さん、レポートありがとうございます。
  - コマンド タグ log_line_prefix プレースホルダー %i を修正してスペース文字を許可します。
  - --exclude-line オプションを修正し、保存が有効で --noreport が使用されている場合に古いディレクトリを削除します。
  - 「バキュームアクティビティテーブル」のタイプミスを修正。パッチを提供してくれた Nicolas Gollet に感謝します。
  - 自動バキューム レポートを修正しました。パッチを提供してくれた Nicolas Gollet に感謝します。
  - pgbadger のロゴの作者である Damien Cazeils とコメント内の英語を修正しました。パッチを提供してくれた Thibaut Madelaine に感謝します。
  - -f オプションに pgbouncer ログ形式に関する情報を追加します。 clomdd さん、レポートありがとうございます。
  - ドキュメントに --normalized-only 情報を追加します。
  - 以前のパッチで導入された日付/時刻の壊れたレポートを修正しました。
  - log_duration=on および log_statement=all の場合の期間とクエリの関連付けを修正します。レポートを提供してくれた Eric Jensen に感謝します。
  - 勧告ロックに関するメッセージの正規化を修正しました。レポートを提供してくれた Thibaut Madelaine に感謝します。
  - auto_explain 出力のレポートを修正しました。 fch77700さん、ご報告ありがとうございます。
  - 標準入力からのログ エントリによる不要なログ形式の自動検出を修正します。報告してくれた Jesus Adolfo Parra に感謝します。
  - 正規表現の "stop" 文字に左開き括弧を追加して、プレフィックス内の DB クライアントを検索し、ソース ポートを含む PostgreSQL クライアント文字列形式を処理します。パッチを提供してくれた Jon Nelson に感謝します。
  - いくつかのスペルミスを修正します。パッチを提供してくれた Jon Nelson に感謝します。
  - 一意のセッション ID として %c (セッション ID) が %p (pid) を置き換えることを許可します。 Jerryliuk さん、レポートありがとうございます。
  - pgbadger が、おそらく 10.0 で使用されるデフォルトの log_line_prefix を解析できるようにします: '%m [%p] '
  - インタープリター呼び出しで欠落している最初の行を修正します。
  - CSV レポートで欠落している平均値を修正します。富田洋介さん、レポートありがとうございました。
  - autodetect_format() メソッドのエラー メッセージを修正しました。
  - --start-monday オプションを追加して、暦週をデフォルトの日曜日ではなく月曜日から開始します。機能リクエストをくださった Joosep Mae に感謝します。
  - --histo-average オプションを修正します。レポートを提供してくれた Yves Martin に感謝します。
  - ドキュメント内の --ssh-option の複数形を削除します。 mark-a-s さん、レポートありがとうございます。
  - --exclude-time フィルターを修正し、不要な行をスキップするコードと進行状況バーを更新するコードを書き換えます。レポートを提供してくれた Michael Chesterton に感謝します。
  - プレフィックス内の %h の代わりに %r プレースホルダーのサポートを修正しました。

## v9.0 · 2016-09-02 {#v9-0}

pgBadger のこのメジャー リリースは、3 をブートストラップするためのポートであり、すべてのリソース ファイル (CSS および Javascript) のバージョン アップグレードです。いくつかのバグ修正と機能強化もあります。

古い増分レポートとの下位互換性が維持される場合があります。

  - リソース ファイルのソースとライセンスは、専用のサブディレクトリに配置されるようになりました。 pgbager スクリプトに埋め込まれた縮小バージョンを更新するためのスクリプトが追加されました。ヘルプと機能リクエストを提供してくれた Christoph Berg に感謝します。

  - log_connection が有効で、log_line_prefix に接続文字列が含まれていない場合は、接続文字列から user/database/host の検出を試みます。
    正規表現を拡張して、データベース名、ユーザー名、クライアント IP アドレス、およびアプリケーション名を自動検出します。現在の正規表現は次のとおりです。

    	db => qr/(?:db|database)=([^,]*)/;
    	user => qr/(?:user|usr)=([^,]*)/;
    	client => qr/(?:client|remote|ip|host)=([^,]*)/;
    	appname => qr/(?:app|application)=([^,]*)/;
    
  - 新しい CSS および Javascript ファイル用のサブディレクトリを作成することにより、増分モードでの古いバージョンの pgbadger との下位互換性を追加します。このサブディレクトリには、pgbadger のメジャー バージョン番号が付けられています。
  - 新しいフォント サイズでは小さすぎる pgbadger ロゴのサイズを大きくします。

  - すべてのレポートの詳細情報を正規化します。

  - ロック レポートの重複コピー アイコンを修正しました。

  - セッション時間のヒストグラムに欠落していたグラフを修正しました。レポートを提供してくれた Guillaume Lelarge に感謝します。

  - リソース ファイルで使用されるライセンスを記録した LICENSE ファイルを追加します。パッチを提供してくれた Christoph Berg に感謝します。

  - jqplot ライブラリにパッチを追加して、いくつかのチャートをダウンロードしようとしたときの無限ループを修正します。この問題の解決に協力してくれた Julien Tachoires に感謝します。
  - Script tools/updt_embedded_rsc.pl は、リソース ファイル resources/jquery.jqplot.js にパッチを適用しますが、すでに適用されている場合には文句を言いません。

  - 円グラフ データセットの末尾にある最後のカンマを 1 つ削除します。 Julien Tachoires さんのレポートに感謝します。

  - 正規化エラーの表示変更

  - 未使用または自動生成されたファイルを削除します

  - すべてのリソース ファイル (js+css) を更新し、pgbadger で使用される JavaScript ライブラリのソースを含めるディレクトリを作成します。新しいスクリプト tools/updt_embedded_rsc.pl もあり、これらのファイルの縮小バージョンを生成し、pgbadger に埋め込むために使用できます。  このスクリプトは、FontAwesome.otf オープン TrueType フォントを fontawesome.css ファイルに埋め込みます。
