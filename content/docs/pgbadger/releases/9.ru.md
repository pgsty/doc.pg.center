Здесь полностью сохранена история изменений pgBadger 9.x из исходного проекта, от новых версий к старым.

## v9.2 · 2017-07-27 {#v9-2}

Этот выпуск pgBadger с исправлениями добавляет несколько новых возможностей.

  * Добавлен отчёт о расстоянии и оценке контрольных точек.
  * В форматировщик кода SQL добавлена поддержка ключевых слов AWS Redshift.
  * В удалённый режим добавлено автоматическое определение формата журнала,
    позволяющее удалённо разбирать журнал pgbouncer вместе с журналом PostgreSQL.

Также исправлены ошибки и улучшены возможности.

  - Исправлены отчёты с гистограммой, не отображавшей данные выше последнего диапазона.
  - Исправлен разбор journalctl без шаблона номера строки журнала ([%l-n]).
    Спасибо Christian Schmitt за сообщение.
  - Добавлен отчёт о расстоянии и оценке контрольных точек. Спасибо jjsantam
    за запрос функции.
  - Дополнено описание действий сценария обновления файлов CSS и JavaScript
    tools/updt_embedded_rsc.pl.
  - Если все файлы журналов пусты, предупреждение не выводится, код завершения — 0.
  - В build_log_line_prefix_regex() исправлено отсутствие %n при поиске в
    %regex_map. Спасибо ghosthound за патч.
  - Уровень ошибки "FATAL: cannot use CSV" изменён на WARNING. Спасибо kong1man
    за сообщение.
  - Исправлено предупреждение об использовании неинициализированного значения.
    Спасибо Payal за сообщение.
  - Permission denied добавлено в нормализацию ошибок.
  - pgbadger обновлён до последнего коммита pgFormatter 5bdc018.
  - Добавлена поддержка ключевых слов AWS Redshift. Спасибо cavanaug за запрос функции.
  - Исправлено отсутствие запроса в отчёте о временных файлах, если запрос был
    отменён. Спасибо Fabrizio de Royes Mello за сообщение.
  - Запрос с параметрами привязки нормализуется с заменой на ?.
  - Добавлена проверка, предотвращающая конечное время раньше начального.
    Спасибо Christophe Courtois за патч.
  - Исправлено множество опечаток и грамматических ошибок. Название 'pgBadger'
    используется для программы, но не двоичного файла; применяются официальные
    написания PgBouncer, GitHub и CSS. Файл POD синхронизирован с README.
    Спасибо Euler Taveira за патч.
  - Исправлено меню: при --disable-type проверка top_cancelled_info и закрытие
    списка должны находиться внутри проверки disable_type. Заодно выровнена
    проверка disable_lock. Спасибо Euler Taveira за патч.
  - Исправлено использование неинициализированного значения. Спасибо johnkrugger
    за сообщение.
  - Удалена попытка читать удалённый файл журнала при автоматическом определении
    формата. Спасибо clomdd за сообщение.
  - В удалённый режим добавлено автоматическое определение формата для разбора
    журнала pgbouncer вместе с журналом PostgreSQL.
  - Исправлено неверное увеличение числа сеансов после проверки строки журнала.
    Спасибо Achilleas Mantzios за сообщение.
  - Незначительно переформатировано описание pgBadger.
  - Удалены повторяющиеся сведения из документации. Спасибо cscatolini за патч.

## v9.1 · 2017-01-24 {#v9-1}

Этот выпуск pgBadger с исправлениями добавляет несколько новых возможностей.

  * Добавлен отчёт о распределении классов ошибок, когда SQLState доступен в
    log_line_prefix (см. заполнитель %e).
  * Форматировщик SQL обновлён до кода pgFormatter v1.6.
  * Улучшена нормализация сообщений об ошибках.
  * Добавлен параметр --normalized-only для создания текстового файла со всеми
    найденными в журнале нормализованными запросами и их количеством.
  * Разрешено использовать %c (идентификатор сеанса) вместо %p (PID) как
    уникальный идентификатор сеанса.
  * Сообщения об ожидании блокировок добавлены в отчёты событий.
  * Добавлен параметр --start-monday, начинающий календарную неделю с понедельника,
    а не с воскресенья по умолчанию.

Также исправлены ошибки и улучшены возможности.

  - Добавлен отчёт о распределении классов ошибок, когда SQLState доступен в
    префиксе строки журнала. Спасибо jacks33 за запрос функции.
  - Исправлен глобальный инкрементальный индекс при изменении размера. Спасибо
    clomdd за сообщение.
  - Заполнитель %i для тега команды в log_line_prefix теперь допускает пробел.
  - Исправлены параметры --exclude-line и удаление устаревшего каталога при
    включённом хранении с --noreport.
  - Исправлена опечатка в "vacuum activity table". Спасибо Nicolas Gollet за патч.
  - Исправлен отчёт autovacuum. Спасибо Nicolas Gollet за патч.
  - Исправлены автор логотипа pgbadger — Damien Cazeils — и английский текст
    комментариев. Спасибо Thibaut Madelaine за патч.
  - В параметр -f добавлены сведения о формате журнала pgbouncer. Спасибо
    clomdd за сообщение.
  - В документацию добавлены сведения о --normalized-only.
  - Исправлен повреждённый отчёт даты и времени из предыдущего патча.
  - Исправлено сопоставление длительности и запроса при log_duration=on и
    log_statement=all. Спасибо Eric Jensen за сообщение.
  - Исправлена нормализация сообщений о рекомендательных блокировках. Спасибо
    Thibaut Madelaine за сообщение.
  - Исправлен отчёт вывода auto_explain. Спасибо fch77700 за сообщение.
  - Устранено нежелательное автоматическое определение формата журнала по записи
    из stdin. Спасибо Jesus Adolfo Parra за сообщение.
  - Открывающая круглая скобка добавлена в стоп-символы регулярного выражения
    поиска клиента БД в префиксе, чтобы поддержать строку клиента PostgreSQL с
    исходным портом. Спасибо Jon Nelson за патч.
  - Исправлены орфографические ошибки. Спасибо Jon Nelson за патч.
  - Разрешено использовать %c (идентификатор сеанса) вместо %p (PID) как
    уникальный идентификатор сеанса. Спасибо Jerryliuk за сообщение.
  - pgbadger может разбирать стандартный log_line_prefix, вероятно используемый
    в 10.0: '%m [%p] '
  - Восстановлена отсутствовавшая первая строка с вызовом интерпретатора.
  - Исправлено отсутствие значений Avg в отчёте CSV. Спасибо Yosuke Tomita за сообщение.
  - Исправлено сообщение об ошибке в методе autodetect_format().
  - Добавлен --start-monday, начинающий календарную неделю с понедельника вместо
    воскресенья. Спасибо Joosep Mae за запрос функции.
  - Исправлен параметр --histo-average. Спасибо Yves Martin за сообщение.
  - Из документации удалена форма множественного числа --ssh-option. Спасибо
    mark-a-s за сообщение.
  - Исправлен фильтр --exclude-time; переписан код пропуска нежелательных строк
    и обновления индикатора выполнения. Спасибо Michael Chesterton за сообщение.
  - Исправлена поддержка заполнителя %r в префиксе вместо %h.

## v9.0 · 2016-09-02 {#v9-0}

Этот основной выпуск pgBadger переносит интерфейс на Bootstrap 3 и обновляет
версии всех файлов ресурсов (CSS и JavaScript). Также исправлены ошибки и
улучшены возможности.

Возможно сохранение обратной совместимости со старыми инкрементальными отчётами.

  - Исходный код и лицензии файлов ресурсов теперь находятся в отдельном
    подкаталоге. Добавлен сценарий обновления их минифицированных версий,
    встроенных в сценарий pgbadger. Спасибо Christoph Berg за помощь и запрос функции.

  - Если включён log_connection, а log_line_prefix не содержит пользователя,
    базы данных и узла, предпринимается попытка определить их из строк соединения.
    
    Расширены регулярные выражения для автоматического определения имени базы
    данных, пользователя, IP-адреса клиента и имени приложения. Теперь они такие:
    
    	db => qr/(?:db|database)=([^,]*)/;
    	user => qr/(?:user|usr)=([^,]*)/;
    	client => qr/(?:client|remote|ip|host)=([^,]*)/;
    	appname => qr/(?:app|application)=([^,]*)/;
    
  - Добавлена обратная совместимость инкрементального режима со старыми версиями
    pgbadger: для новых файлов CSS и JavaScript создаётся подкаталог, названный
    номером основной версии pgbadger.
    
  - Увеличен логотип pgbadger, который выглядел слишком маленьким с новым размером шрифта.

  - Нормализованы подробные сведения во всех отчётах.

  - Удалён повторяющийся значок копирования в отчёте блокировок.

  - Восстановлена отсутствовавшая диаграмма гистограммы времени сеансов. Спасибо
    Guillaume Lelarge за сообщение.

  - Добавлен файл LICENSE с лицензиями файлов ресурсов. Спасибо Christoph Berg за патч.

  - В библиотеку jqplot добавлен патч, устраняющий бесконечный цикл при попытке
    загрузить некоторые диаграммы. Спасибо Julien Tachoires за помощь в решении проблемы.
    
  - Сценарий tools/updt_embedded_rsc.pl применяет патч к файлу ресурсов
    resources/jquery.jqplot.js и не сообщает об ошибке, если патч уже применён.

  - Удалена последняя одиночная запятая в конце набора данных круговой диаграммы.
    Спасибо Julien Tachoires за сообщение.

  - Изменено отображение нормализованной ошибки.

  - Удалены неиспользуемые и автоматически создаваемые файлы.

  - Обновлены все файлы ресурсов (JS и CSS), создан каталог с исходным кодом
    библиотек JavaScript, используемых в pgbadger. Новый сценарий
    tools/updt_embedded_rsc.pl создаёт минифицированные версии этих файлов и
    встраивает их в pgbadger. Он также встраивает открытый шрифт TrueType
    FontAwesome.otf в файл fontawesome.css.
