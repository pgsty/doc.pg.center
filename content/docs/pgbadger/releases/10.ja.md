## v10.3 · 2019-02-14 {#v10-3}

pgBadger のこのリリースは、ログ形式の自動検出の問題とユーザーから報告された別の pgBouncer ログ解析の問題を修正するメンテナンス リリースです。新しい機能もあります。

    -o | --outfileオプションを複数回指定し、1つのコマンドで複数の形式を出力できるようになりました。例：
        pgbadger -o out.html -o out.json /log/pgsql-11.log
    HTMLとJSONの2つのレポートが生成され、対応する2つのファイルに保存されます。

いくつかのバグ修正と機能強化もあります。

  - データベース、ユーザー、クライアント、またはアプリケーションに関するフィルターが要求された場合の統計レポートを修正します。一部のクエリは報告されませんでした。
  - pg>=10 のデフォルトのログ行プレフィックスの自動検出を修正しました。
  - 「非標準」ログ行プレフィックスを持つログ ファイルの自動検出を修正します。 --prefix で %t、%m、%n、および %p または %c を指定する場合は、形式を stderr に設定します。レポートを提供してくれた Alex Danvy に感謝します。
  - 行末の余分なスペースを削除します。
  - syslog パーサーに最小限のテストを追加します。
  - autodetect_format() の呼び出しを修正します。
  - maxlength が使用されている場合の Truncate ステートメント。パッチを提供してくれた Thibaud Madelaine に感謝します。
  - 複数の出力形式のテストを追加します。
  - -o | --outfileオプションを複数回指定し、1つのコマンドで複数の形式を出力できるようになりました。例：
      pgbadger -o out.txt -o out.html -o - -x json /log/pgsql-11.log
    この例では、pgbadgerはテキストとHTMLの2つのレポートを生成し、対応する2つのファイルに保存します。さらに、標準出力にJSONレポートを出力します。機能を要望してくださったNikolayに感謝します。
  - 出力フォーマットの検出と出力ファイル名の設定を専用関数 set_output_extension() に移動します。
  - 別の pgBouncer ログ解析の問題を修正します。レポートを提供してくれた Douglas J. Hunley に感謝します。

## v10.2 · 2018-12-27 {#v10-2}

pgBadger のこのリリースは、過去 3 か月間にユーザーから報告された問題を修正するメンテナンス リリースです。いくつかの新機能もあります。

  * pgbouncer 1.8 統計ログ形式のサポートを追加します。
  * JavaScript グラフのタイムゾーンを自動調整します。

新しいコマンド ライン オプションがあります。

  * --exclude-db オプションを追加して、指定したデータベース以外のすべてに関するレポートを計算します。
  * http または ftp リモート PostgreSQL ログ ファイルのダウンロードのサポートを追加します。ログ ファイルは、curl コマンドを使用したダウンロード中に解析され、ディスクには保存されません。 SSH リモート ログ解析では、コマンド ライン引数として uri を使用して、PostgreSQL ログ ファイルを指定できます。
            ssh://localhost/postgresql-10-main.log
            http://localhost/postgresql-10-main.log.gz
            ftp://localhost/postgresql-10-main.log
    
    http および ftp プロトコルでは、uri の最後にログ ファイル形式を指定する必要があります。

            http://localhost/postgresql-10-main.log:stderr
    
    解析するログ ファイルに対して複数の URI を指定できます。これは、リモート ホストに pgbouncer ログ ファイルがあり、ローカル ホストに PostgreSQL ログがある場合に便利です。

    ssh プロトコルでは、リモート モードと同様にワイルド カードも使用できます。例: ssh://localhost/postgresql-10-main.log*

    -r オプションを使用してリモート ログ ファイルを解析する古い構文はまだ機能していますが、廃止されており、将来のバージョンでは削除される可能性があります。


いくつかのバグ修正と機能強化もあります。

  - 推定サイズのファイル (bz2 圧縮ファイルおよびリモート圧縮ファイル) で進行状況バーの終わりを調整します。
  - 著作権の年を更新します。
  - リモート ログ ファイルを解析するための URI 表記に関する情報を追加します。
  - 圧縮されたリモート ファイルの解析の終了時に進行状況が 100% に到達するように強制します。
  - 一時ファイル レポートのクエリ内の PL/pgSQL 関数呼び出しに関する情報を抽出します。情報は詳細表示ブロックに追加されます。
  - csv ファイルの進行状況バーを修正しました。
  - ログ ファイルではなく入力ファイルとしてバイナリ ファイルを読み取る問題を修正しました。
  - クエリーのHTML出力をUTF8にエンコードし、「Wide character in print」メッセージが出ないようにしました。報告してくださったColin 't Hartに感謝します。
  - Add チェックポイント距離キー/距離ピークの値。
  - pgbouncer の解析とリクエスト スループット レポートを修正します。 Levente Birta さんのレポートに感謝します。
  - 入力形式として csv ではなく csvlog の使用を修正しました。
  - pgbouncer 1.8 統計ログ形式のサポートを追加します。 Levente Birta さんのレポートに感謝します。
  - csvlog で無効になっている並列処理に関する警告を追加します。 cstdenis さん、レポートありがとうございます。
  - -j および -J オプションの csvlog 形式による単一プロセスの強制に関する使用状況出力に情報を追加します。 cstdenis さん、レポートありがとうございます。
  - SSH 経由の増分分析中の複数行ログの不明な行形式エラーを修正します。 Wooyoung Cho さん、レポートありがとうございます。
  - -k (--insecure) オプションをcurl コマンドに追加して、自己署名証明書を使用してサーバーからログをダウンロードできるようにします。
  - JavaScript グラフのタイムゾーンを自動調整します。機能リクエストをくださった Massimino Sala に感謝します。
  - pgBadgerによるHTTP経由のログファイルのダウンロードに対応しました。例：
        /usr/bin/pgbadger http://www.mydom.com/postgresql-10.log
  - curl コマンドを使用してダウンロード中にファイルを解析します。
  - ドキュメントを修正します。パッチを提供してくれた 0xflotus に感謝します。
  - 追加のコードをクリーンアップした後、バインド パラメーターの置換が欠落している問題の修正を再適用します。レポートを提供してくれた Bernhard J. M. Grun に感謝します。
  - --exclude-db オプションを追加して、指定したデータベース以外のすべてに関するレポートを計算します。このオプションは複数回使用できます。

  - pgbadger、ポッド、および README を同期し、いくつかの構文エラーを修正します。パッチを提供してくれた Christoph Berg に感謝します。

  - インクリメンタル モードで CSS の URI を修正します。報告してくれた Floris van Nee に感謝します。
  - STDIN からログを検索する際の致命的なエラーを修正しました。レポートを提供してくれた Jacek Szpot に感謝します。
  - OSX ビルドで使用される SED を修正します。パッチを提供してくれた Steve Newson に感謝します。

  - SQL::Beautify を pgFormatter::Beautify の v3.1 に置き換えます。

## v10.0 · 2018-09-09 {#v10-0}

pgBadger のこのリリースは、いくつかの新機能を追加し、前回のリリース以降にユーザーから報告されたすべての問題を修正するメジャー リリースです。

  * pgbouncer syslog ログ ファイル形式のサポートを追加します。
  * すべての auto_explain 形式 (text、xml、json、yaml) へのサポートを追加します。
  * log_line_prefix の %q プレースホルダーへのサポートを追加します。
  * Michael Paquier 拡張機能の jsonlog 形式を追加します。-f jsonlog pgbadger を使用すると、ログを解析できるようになります。
  * SQL フォーマッタ/整形を pgFormatter の v3.0 に置き換えます。

新しいコマンドライン オプションがいくつかあります。

  - JSON 出力を整形するために --prettify-json コマンド ライン オプションを追加します。
  - --log-timezone +/-XX コマンド ライン オプションを追加して、解析される前にログ ファイルから読み取られる日付/時刻を調整するために使用する必要があるタイムゾーンの GMT からの時間数を設定します。クライアントのタイムゾーンが同じでない場合でも、-Z を使用してグラフのタイムゾーンを調整する必要がある場合があることに注意してください。
  - --include-time オプションを追加すると、表示したくない時間をすべて除外するのではなく、表示したい時間を選択できるようになります (--exclude-time)。

pgBadger プロジェクトと著作権は、Dalibo からプロジェクトの作成者および公式メンテナーに譲渡されました。リンクを更新してください:

  - Web サイト: http://pgbadger.darold.net/
