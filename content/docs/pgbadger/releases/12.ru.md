Здесь полностью сохранена история изменений pgBadger 12.x из исходного проекта, от новых версий к старым.

## v12.4 · 2023-12-25 {#v12-4}

Это выпуск pgBadger с исправлениями проблем, о которых
пользователи сообщили после предыдущего выпуска.

  - Исправлен отчёт pgbouncer для версии 1.21. Спасибо Ales Zeleny за патч.
  - Число параллельных процессов Perl больше не может превышать число файлов.
    Спасибо maliangzhu за сообщение.
  - Исправлен регрессионный тест, не работавший с версии 12.3. Спасибо ieshin
    за сообщение.
  - Исправлены случаи, когда записи LOG учитывались как записи уровня ERROR.
    Спасибо Matti Linnanvuori за сообщение.

## v12.3 · 2023-11-27 {#v12-3}

Это выпуск pgBadger с исправлениями проблем, о которых
пользователи сообщили после предыдущего выпуска. Он также добавляет новые возможности:

  * Добавлен параметр --include-pid, позволяющий включать в отчёт только события,
    связанные с PID сеанса (%p). Его можно указывать несколько раз. Спасибо
    Henrietta Dombrovskaya за запрос функции.
  * Добавлен параметр --include-session, позволяющий включать в отчёт только
    события, связанные с идентификатором сеанса (%c). Его можно указывать
    несколько раз. Спасибо Henrietta Dombrovskaya за запрос функции.
  * Добавлен параметр --dump-raw-csv, который только разбирает журнал и выводит
    сведения в формате CSV. Дальнейшая обработка не выполняется, отчёт не
    создаётся. Спасибо Henrietta Dombrovskaya за запрос функции.

Полный список изменений и благодарностей:

  - pgFormatter обновлён до версии 5.5.
  - Исправлена конечная дата разбора в формате jsonlog. Спасибо jw1u1 за сообщение.
  - Исправлена опечатка в «Sessions per application». Спасибо fairyfar за патч.
  - Исправлена ошибка диаграммы «INSERT/UPDATE/DELETE Traffic». Спасибо fairyfar
    за патч.
  - Исправлен разбор непривязанных строк с запросами привязки. Спасибо youxq
    за сообщение.
  - Исправлен отчёт Analyze per table для новых версий PG. Спасибо Jean-Christophe
    Arnu за патч.
  - Исправлен анализатор записей syslog, когда отметка времени syslog содержит
    миллисекунды. Спасибо Pavel Rabel за сообщение.

## v12.2 · 2023-08-20 {#v12-2}

Это выпуск pgBadger с исправлениями проблем, о которых
пользователи сообщили после предыдущего выпуска. Он также добавляет две возможности:

  * Добавлена поддержка максимальной, средней и минимальной длительности
    autovacuum. Спасибо Francisco Reinolds за патч.
  * Добавлена поддержка среднего времени ожидания pgbouncer. Спасибо Francisco
    Reinolds за патч.

Полный список изменений и благодарностей:

  - Исправлен повреждённый вывод HTML, когда имя приложения содержит <...>.
    Спасибо Fabio Geiss за сообщение.
  - Исправлено неверное сопоставление непривязанных строк при применении фильтра
    по базе данных. Спасибо jcasanov за сообщение.
  - Исправлен разбор префикса logplex.
  - Исправлено обнаружение непривязанных строк logplex.
  - Исправлен разбор строки `system usage: CPU: ...` от `autovacuum`. Спасибо
    Francisco Reinolds за патч.
  - При выводе в stdout каталог вывода больше не добавляется в начало пути.
  - Унифицирована подпись Average Query Duration. Спасибо Francisco Reinolds
    за патч.
  - Обновлена документация по новым параметрам pgbadger. Спасибо Francisco
    Reinolds за патч.
  - Исправлен случай, когда разбор не прерывался, хотя ни один файловый
    дескриптор открыть не удалось. Спасибо vp за сообщение.
  - В справку добавлены сведения об обязательных заполнителях журнала %p/%t.
    Спасибо Christophe Courtois за патч.
  - Исправлен параметр --retention. Спасибо Bertrand Bourgier за патч.
  - Восстановлена удалённая коммитом 0e5c7d5 очистка каталога вывода при заданном
    каталоге вывода HTML. Спасибо Bertrand Bourgier за сообщение.
  - Исправлено расширение вывода, когда каталог назначения содержит символ,
    требующий экранирования в регулярном выражении. Спасибо Bertrand Bourgier
    за патч.
  - Для порта Windows вызовы POSIX::strftime("%s", ....) заменены вызовом
    localtime. Спасибо Bertrand Bourgier за патч.
  - Исправлена очистка каталога вывода HTML. Спасибо Bertrand Bourgier за патч.
  - Для URL explain по умолчанию используется https. Спасибо Philipp Trulson
    за патч.

## v12.0 · 2022-09-13 {#v12-0}

Этот основной выпуск pgBadger исправляет проблемы, о которых пользователи
сообщили за предыдущие пять месяцев. Как обычно, добавлены новые возможности и улучшения:

  * Удалена поддержка вывода Tsung.
  * Повышена производительность pgbadger при подстановке сотен параметров привязки.
  * Удалён параметр -n | --nohighlight, который не используется после обновления
    до pgFormatter 4.
  * Для отправки плана auto_explain на explain.depesz.com используется метод
    POST, что позволяет избежать ограничения длины параметров GET.
  * Параметры --exclude-query и --include-query применяются к трассировкам bind/parse.
  * В документацию добавлена ссылка на примеры отчётов pgBadger.

Полный список изменений и благодарностей:

  - Исправлен сбой месячных отчётов с сообщением «log file ... must exists».
    Спасибо Jaume Sabater за сообщение.
  - Исправлено отладочное сообщение о начале разбора pgbouncer при вводе из
    stdin. Спасибо aleszeleny за сообщение.
  - Удалена поддержка вывода Tsung.
  - Значительно повышена производительность pgbadger при подстановке параметров
    привязки: при сотнях параметров pgbadger мог работать бесконечно. Спасибо
    Monty Mobile за сообщение.
  - Исправлена документация о кодах возврата pgBadger и неверные коды возврата
    в нескольких местах. Спасибо Jaume Sabater за сообщение.
  - Исправлено несколько опечаток. Спасибо David Gilman за патч.
  - Удалён параметр -n | --nohighlight, который не используется после обновления
    до pgFormatter 4. Спасибо Elena Indrupskaya за сообщение.
  - Внесено множество исправлений в документацию pgbadger. Спасибо Elena
    Indrupskay из Postgres Pro за патч.
  - Параметры --log-timezone и --timezone теперь поддерживают получасовой сдвиг:
    значение может быть целым, например 2, или дробным, например 2.5. Спасибо
    Mujjamil-K за запрос функции.
  - Для --exclude-app и --exclude-client разрешены регулярные выражения. Спасибо
    rdnkrkmz за запрос функции.
  - Разрешено использование --explain-url с предыдущим коммитом и восстановлено
    ограничение на текстовый формат explain.
  - Для отправки плана auto_explain на explain.depesz.com используется метод
    POST, что позволяет избежать ограничения длины параметров GET. Спасибо
    hvisage за сообщение.
  - Параметры --exclude-query и --include-query применяются к трассировкам
    bind/parse. Спасибо Alec Lazarescu за сообщение.
  - Исправлен разбор статистики autovacuum из журналов RDS. Спасибо David
    Gilman за сообщение.
  - Исправлена передача формата журнала при разборе удалённого журнала. Спасибо
    spookypeanut за сообщение.
  - В документацию добавлена ссылка на примеры отчётов pgBadger.
  - Исправлены отчёты Session per user. Спасибо vitalca за сообщение.
  - Исправлен разбор jsonlog из PG15.
  - Исправлен текстовый отчёт об ошибках/событиях. Спасибо Michael Banck за патч.
