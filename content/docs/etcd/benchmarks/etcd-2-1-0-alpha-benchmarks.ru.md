## Физические машины {#physical-machines}

Тип машины GCE n1-highcpu-2

- 1x выделенный локальный SSD, подключённый в /var/lib/etcd
- 1x выделенный медленный диск для ОС
- 1.8 GB памяти
- 2x CPU
- etcd версии 2.1.0 alpha

## Кластер etcd {#etcd-cluster}

3 участника etcd, каждый работает на отдельной машине

## Тестирование {#testing}

Запустите ещё одну машину и с помощью [инструмента HTTP-тестирования hey][hey] отправляйте запросы каждому участнику etcd. Подробные инструкции приведены в [руководстве по разработке тестов производительности][hack-benchmark].
