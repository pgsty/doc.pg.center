## コードカバレッジ {#code-coverage}

pgBackRest は、`/src` のコア C コードを完全に function/branch/line カバーすることを目指しています。

関数/行は例外なく完全にカバーされています。

ブランチ カバレッジでは、マクロ内のブランチと `assert()` 呼び出しは除外されます。マクロには独自の単体テストがあるため、マクロが出現するすべての場所でテストする必要はありません。アサートは常に true であるべきケースをテストするため、完全な分岐カバレッジを持つことは期待されていません。
