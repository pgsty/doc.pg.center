## 时间线 {#timeline}

- **2026 年 5 月：升级至 PostgreSQL 16.9 内核**\
  主分支将 PostgreSQL 内核从 14.4 升级至 PostgreSQL 16.9，为 MPP 平台带来现代 PostgreSQL 特性、性能改进和安全修复。\
  [公告](https://cloudberry.apache.org/blog/postgresql16-for-apache-cloudberry-202606)
- **2026 年 4 月：发布 Apache Cloudberry（孵化中）2.1.0**\
  2.1.0 版本发布，在 Apache 孵化器中延续了版本发布的势头，带来进一步的功能增强和社区贡献。\
  [2.1 预览](https://cloudberry.apache.org/blog/apache-cloudberry-2.1.0-preview) · [公告](https://cloudberry.apache.org/blog/announce-apache-cloudberry-2.1.0) · [变更日志](https://cloudberry.apache.org/releases/2.1.0-incubating)
- **2025 年 7 月：首个 Apache 版本 v2.0.0 发布**\
  Apache Cloudberry（孵化中）2.0.0 发布，标志着首个正式 Apache 版本问世，并确立了 Apache 治理下的项目发布流程。\
  [2.0 预览](https://cloudberry.apache.org/blog/apache-cloudberry-2.0-preview-key-features-and-improvements-ahead) · [公告](https://cloudberry.apache.org/blog/announce-apache-cloudberry-2.0.0) · [新特性](https://cloudberry.apache.org/blog/whats-new-in-apache-cloudberry-2.0.0) · [变更日志](https://cloudberry.apache.org/releases/2.0.0-incubating)
- **2024 年 10 月：加入 Apache 孵化器**\
  Cloudberry Database 经投票获准加入 Apache 孵化器，更名为 Apache Cloudberry，并在 Apache 软件基金会孵化器的支持下开始孵化历程。\
  [公告](https://cloudberry.apache.org/blog/cloudberry-database-enters-the-apache-incubator)
- **2024 年 5 月：Greenplum Database 闭源**\
  Greenplum Database 归档了其 GitHub 仓库并闭源。这一事件巩固了 Apache Cloudberry 作为开源继承者的地位。它延续着基于 PostgreSQL 的 MPP 数据库技术路线。
- **2023 年 6 月：Cloudberry Database 开源**\
  Cloudberry Database 正式开源，邀请全球开发者社区共同参与、贡献和建设。
- **2022 年 6 月：项目启动**\
  HashData 启动了源自 Greenplum Database 7 的 Cloudberry Database 项目。团队将 PostgreSQL 内核从 12.x 升级至 14.4，为未来发展奠定了现代化基础。
