它每天能够稳定、高效地同步数百亿条数据，已有 3000 多家企业在生产环境中使用。

从 [SeaTunnel 2.3.11](https://github.com/apache/seatunnel/releases/tag/2.3.11) 开始，该平台通过专用连接器原生支持 Apache Cloudberry。

详细使用指南参见：

- Cloudberry 源连接器：https://seatunnel.apache.org/docs/2.3.11/connector-v2/source/Cloudberry
- Cloudberry 目标连接器：https://seatunnel.apache.org/docs/2.3.11/connector-v2/sink/Cloudberry

如需技术支持或报告问题，请访问 [Apache SeaTunnel GitHub 仓库](https://github.com/apache/seatunnel)。
