## 概要 {#synopsis}

```sql
DROP GROUP [IF EXISTS] <name> [, ...]
```

## 描述 {#description}

`DROP GROUP` 是 [DROP ROLE](/cloudberry/reference/sql-stmts/drop-role/) 的别名。

## 兼容性 {#compatibility}

SQL 标准中没有 `DROP GROUP` 语句。
