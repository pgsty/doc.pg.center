MongoDB Query Language (MQL) commands are direct instructions for managing and interacting with your database server. They are essential for performing administrative tasks, optimizing performance, and maintaining security.

See [wire-command support and common fields](/documentdb/reference/commands/diagnostic/wire-protocol/) for a source-correlated inventory, shared request metadata, compatibility responses, and provider-dependent command availability.
