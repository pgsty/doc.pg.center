`$tsIncrement` 运算符返回时间戳中的增量值。

## 语法 {#syntax}

```javascript
{
  $tsIncrement: <expression>
}
```

## 参数 {#parameters}

| 参数 | 说明 |
| --- | --- |
| **`expression`** | 求值结果为时间戳的表达式。如果表达式的求值结果不是时间戳，`$tsIncrement` 会返回错误。 |
{.fields}

### 示例 1：从审计时间戳中提取增量 {#example-1-extract-increment-from-audit-timestamp}

从审计日志的最后更新时间戳中提取增量值。

```javascript
db.stores.aggregate([
  { $match: {"_id": "2cf3f885-9962-4b67-a172-aa9039e9ae2f"} },
  {
    $project: {
      name: 1,
      lastUpdatedIncrement: {
        $tsIncrement: "$auditLog.lastUpdated"
      }
    }
  }
])
```

此查询返回以下结果。

```json
[
  {
    "_id": "2cf3f885-9962-4b67-a172-aa9039e9ae2f",
    "name": "First Up Consultants | Bed and Bath Center - South Amir",
    "lastUpdatedIncrement": Long("5")
  }
]
```
