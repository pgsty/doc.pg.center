`$dayOfMonth` 运算符从日期值中提取当月的第几天（1–31），可用于按当月的第几天对文档分组或筛选。

## 语法 {#syntax}

```javascript
{
  $dayOfMonth: <dateExpression>
}
```

## 参数 {#parameters}

| 参数              | 描述                                                     |
| ---------------------- | --------------------------------------------------------------- |
| **`<dateExpression>`** | 要从中提取当月第几天的日期表达式。 |
{.fields}

### 示例 1：提取当月的第几天 {#example-1-extract-day-of-the-month}

此查询使用 `$dayOfMonth` 运算符，从 `lastUpdated` 时间戳中提取当月的第几天（1–31），将该字段的日分量单独取出，用于报表或分组。

```javascript
db.stores.aggregate([
  {
    $match: { _id: "e6410bb3-843d-4fa6-8c70-7472925f6d0a" }
  },
  {
    $project: {
      _id: 0,
      dayOfMonth: { $dayOfMonth: "$lastUpdated" }
    }
  }
])
```

此查询返回以下结果。

```json
[
  {
    "dayOfMonth": "4"
  }
]
```
