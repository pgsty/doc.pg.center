`$dayOfYear` 运算符从日期值中提取当年的第几天，其中 1 表示 1 月 1 日。它可用于按一年中的第几天对文档分组或筛选。

## 语法 {#syntax}

```javascript
{
  $dayOfYear: <dateExpression>
}
```

## 参数 {#parameters}

| 参数              | 描述                                                    |
| ---------------------- | -------------------------------------------------------------- |
| **`<dateExpression>`** | 要从中提取当年第几天的日期表达式。 |
{.fields}

### 示例 1：提取当年的第几天 {#example-1-extract-day-of-the-year}

此查询使用 `$dayOfYear` 运算符，从 `lastUpdated` 时间戳中提取日期是一年中的第几天（1–366）。

```javascript
db.stores.aggregate([
  {
    $match: { _id: "e6410bb3-843d-4fa6-8c70-7472925f6d0a" }
  },
  {
    $project: {
      _id: 0,
      dayOfYear: { $dayOfYear: "$lastUpdated" }
    }
  }
])
```

此查询返回以下结果。

```json
[
  {
    "dayOfYear": 339
  }
]
```

```json
{ "dayOfYear": 339 }
```
