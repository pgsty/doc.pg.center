`$rand` 运算符生成介于 0 和 1 之间的随机浮点值。它可用于对文档进行随机采样，或在聚合流水线中创建随机值。

## 语法 {#syntax}

```javascript
{
  $rand: {}
}
```

### 示例 1：添加随机值 {#example-1-add-a-random-value}

此查询为每个商店文档添加一个随机值。

```javascript
db.stores.aggregate([
   { 
     $project: {
       name: 1,
       randomValue: { $rand: {} },
       "sales.totalSales": 1
     }
   },
   { $limit: 2 }
])
```

此查询返回的前两个结果如下：
