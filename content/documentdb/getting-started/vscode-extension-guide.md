> The official website now directs this page to the [current guide](/documentdb/getting-started/vscode-quickstart/). The source document is retained here for existing links.

The canonical guide is the **[Visual Studio Code Quick Start](/documentdb/getting-started/vscode-quickstart/)** — start there to install the extension, connect to a local instance, and create your first collection.

Install the extension from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=ms-azuretools.vscode-documentdb), or from the command line:

```bash
code --install-extension ms-azuretools.vscode-documentdb
```

For feature reference, issues, and release notes, see the [extension repository](https://github.com/microsoft/vscode-documentdb).
