本文为 PGSTY 基于上游文档整理的导读。


pg_tde 2.2.2 面向运维带来两项主要变化：支持通过 KMIP 使用 HashiCorp Vault Enterprise，并改善 WAL 加密性能。

> [!WARNING]
> 上游发布说明指出，pg_tde 2.2.2 与低于 17.10.2 或 18.4.2 的 Percona Distribution for PostgreSQL 版本不兼容。

## 变更内容 {#what-changed}

- 通过 KMIP 支持 HashiCorp Vault Enterprise；此前已经支持 Vault V2 协议。
- 改善 WAL 加密性能。
- 修复 `pg_tde_add_global_key_provider_kmip()` 和 `pg_tde_add_database_key_provider_kmip()` 传入空证书参数时的问题。
- 修复 Vault 提供商在进程 fork 后共享 cURL 句柄时的竞态问题。
- 修复 `pg_wal` 为符号链接时 `pg_tde_archive_decrypt` 和 `pg_tde_restore_encrypt` 的 WAL 归档问题。
- 包含 PostgreSQL 16.15、17.11 和 18.5 前端工具的修复。

## 升级前检查 {#before-you-upgrade}

1. 确认 Percona PostgreSQL 软件包版本满足兼容要求。
2. 检查密钥提供商配置，确认服务器仍然可以读取已有主密钥。
3. 在临时环境测试 WAL 归档和恢复。
4. 将[启用 WAL 加密时的备份流程](/zh/percona/how-to/backup-wal-enabled/)与变更记录一起保存。

完整变更请阅读[pg_tde 2.2.2 发布说明](/zh/percona/release-notes/release-notes-v2.2.2/)。
