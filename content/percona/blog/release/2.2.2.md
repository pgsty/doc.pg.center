An editorial reading note by PGSTY, based on the upstream documentation.


pg_tde 2.2.2 focuses on two operator-facing changes: KMIP support for HashiCorp Vault Enterprise and better WAL encryption performance.

> [!WARNING]
> The upstream release notes state that pg_tde 2.2.2 is incompatible with Percona Distribution for PostgreSQL versions older than 17.10.2 or 18.4.2.

## What changed {#what-changed}

- Add support for HashiCorp Vault Enterprise through KMIP. Vault Enterprise was already supported through the Vault V2 protocol.
- Improve WAL encryption performance.
- Fix empty certificate parameters passed to `pg_tde_add_global_key_provider_kmip()` and `pg_tde_add_database_key_provider_kmip()`.
- Fix a Vault provider race after a process fork.
- Fix WAL archiving with `pg_tde_archive_decrypt` and `pg_tde_restore_encrypt` when `pg_wal` is a symlink.
- Include frontend tool fixes from PostgreSQL 16.15, 17.11, and 18.5.

## Before you upgrade {#before-you-upgrade}

1. Confirm the Percona PostgreSQL package version is compatible.
2. Review the key provider configuration and ensure the server can read existing principal keys.
3. Test WAL archive and restore in a disposable environment.
4. Keep the [backup and WAL encryption procedure](/percona/how-to/backup-wal-enabled/) with the change record.

For the complete upstream changelog, read the [pg_tde 2.2.2 release note](/percona/release-notes/release-notes-v2.2.2/).
