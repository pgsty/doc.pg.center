An editorial reading note by PGSTY, based on the upstream documentation.


pg_tde 2.2.1 is a compatibility and reliability release.

## Highlights {#highlights}

- Add PostgreSQL 16 support.
- Improve `pg_rewind` behavior for pg_tde clusters.
- Fix the `could not find server principal key` error from `pg_tde_basebackup`.
- Build pg_tde with Meson; the upstream release no longer supports building it with `make`.

## Upgrade checks {#upgrade-checks}

Before upgrading, verify that the target Percona PostgreSQL package and the configured provider can read all existing principal keys. Test rewind, recovery, and backup restore in a staging cluster before changing a production primary.
