## Documentation and software {#documentation}

The [upstream welcome page](/ivorysql/about/welcome/) describes IvorySQL as an open-source project proposed by Highgo Software and as Apache licensed. The [IvorySQL software repository](https://github.com/IvorySQL/IvorySQL/blob/master/LICENSE) provides Apache License 2.0; a [copy of that licence](/ivorysql/assets/legal/Apache-2.0.txt) is included here.

The pinned documentation repository has no standalone `LICENSE` or `NOTICE` file. This site retains the project's licensing statement without treating the software licence as a blanket grant for all documentation, screenshots, or third-party material. Original authors, contributors, and other rightsholders retain their rights. Check the original source and its terms before reusing specific material.
