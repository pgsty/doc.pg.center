The Citus API consists of utility functions, metadata tables and views, and configuration parameters. Use these resources to manage distributed tables, shards, and cluster operations.

| [Citus Tables and Views](/citus/reference/api-metadata/) | Metadata tables and views for tracking shards, placements, and cluster state |
| [Configuration Reference](/citus/reference/api-guc/) | Configuration parameters that control Citus behavior |
