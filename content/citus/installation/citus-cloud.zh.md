在 Azure 云上创建集群，是开始使用 Citus 的便捷方式之一。Citus 托管服务以 [Azure Database for PostgreSQL Flexible server](https://techcommunity.microsoft.com/blog/adforpostgresql/postgres-horizontal-scaling-with-elastic-clusters-on-azure-database-for-postgres/4303508) 弹性集群的形式提供。

弹性集群将 Citus 的横向扩展能力带入 Azure Database for PostgreSQL Flexible server，提供内置分片与数据分布能力的全托管 PostgreSQL 方案。
