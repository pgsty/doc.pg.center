## v10.3 · 2019-02-14 {#v10-3}

这是维护版本，修复了用户报告的日志格式自动识别问题，以及另一处 PgBouncer 日志解析问题。同时添加一项功能：

    -o | --outfile 现在可多次指定，使单条命令输出多种格式。例如：
        pgbadger -o out.html -o out.json /log/pgsql-11.log
    将生成 HTML 与 JSON 两份报告，分别保存到对应文件。

其他缺陷修复与功能改进：

  - 修复指定数据库、用户、客户端或应用过滤条件时，部分查询未出现在统计报告中的问题。
  - 修复 PostgreSQL >= 10 默认日志行前缀的自动识别。
  - 修复非标准日志行前缀的格式自动识别；`--prefix` 包含 `%t`、`%m` 或 `%n`，以及 `%p` 或 `%c` 时，将格式设为 stderr。感谢 Alex Danvy 报告。
  - 移除行尾多余空格。
  - 为 syslog 解析器添加最小测试。
  - 修复 `autodetect_format()` 的调用。
  - 使用 maxlength 时截断语句。感谢 Thibaud Madelaine 提供补丁。
  - 添加多种输出格式的测试。
  - `-o | --outfile` 可多次指定，使单条命令输出多种格式。例如：
      pgbadger -o out.txt -o out.html -o - -x json /log/pgsql-11.log
    此命令生成文本和 HTML 报告，保存到对应文件，同时向标准输出写出 JSON 报告。感谢 Nikolay 提出需求。
  - 将输出格式检测与输出文件名设置移入专用函数 `set_output_extension()`。
  - 修复另一处 PgBouncer 日志解析问题。感谢 Douglas J. Hunley 报告。

## v10.2 · 2018-12-27 {#v10-2}

这是维护版本，修复了过去三个月用户报告的问题，并增加以下功能：

  * 支持 PgBouncer 1.8 的 Stats 日志格式。
  * 自动调整 JavaScript 图表的时区。

新增命令行选项与远程读取功能：

  * 添加 `--exclude-db`，生成指定数据库以外的所有报告。
  * 支持通过 HTTP 或 FTP 下载远程 PostgreSQL 日志。使用 curl 在下载过程中解析，日志不会保存到磁盘。SSH 远程解析也可在命令行以 URI 指定日志文件：

            ssh://localhost/postgresql-10-main.log
            http://localhost/postgresql-10-main.log.gz
            ftp://localhost/postgresql-10-main.log

    当时 HTTP 和 FTP 需要在 URI 末尾指定日志格式：

            http://localhost/postgresql-10-main.log:stderr

    可以指定多个日志 URI，适合同时解析远程 PgBouncer 日志和本地 PostgreSQL 日志。

    SSH 协议也支持与远程模式相同的通配符，例如 `ssh://localhost/postgresql-10-main.log*`。

    使用 `-r` 解析远程文件的旧写法仍可用，但当时已标为过时，并可能在未来版本移除。

其他缺陷修复与功能改进：

  - 调整估算文件大小时的进度条结束处理，例如 bz2 文件与远程压缩文件。
  - 更新版权年份。
  - 补充使用 URI 解析远程日志的说明。
  - 远程压缩文件解析完成后强制进度达到 100%。
  - 在临时文件报告的查询中提取 PL/pgSQL 函数调用信息，并追加到详细信息区域。
  - 修复 CSV 文件的进度条。
  - 修复将二进制文件作为输入时误当日志文件读取的问题。
  - 将查询的 HTML 输出编码为 UTF8，避免 `Wide character in print` 消息。感谢 Colin 't Hart 报告。
  - 为检查点距离峰值添加键值信息。
  - 修复 PgBouncer 解析和请求吞吐量报告。感谢 Levente Birta 报告。
  - 修复输入格式使用 csvlog 而非 csv 的问题。
  - 支持 PgBouncer 1.8 Stats 日志格式。感谢 Levente Birta 报告。
  - CSV 日志禁用并行处理时添加警告。感谢 cstdenis 报告。
  - 在用法中补充 csvlog 强制单进程的说明，涉及 `-j` 和 `-J`。感谢 cstdenis 报告。
  - 修复通过 SSH 增量解析多行日志时的未知行格式错误。感谢 Wooyoung Cho 报告。
  - 在 curl 命令中添加 `-k`（`--insecure`），允许从使用自签名证书的服务器下载日志。
  - 自动调整 JavaScript 图表时区。感谢 Massimino Sala 提出需求。
  - 支持 HTTP 日志下载，例如：
        /usr/bin/pgbadger http://www.mydom.com/postgresql-10.log
  - 使用 curl 在下载过程中解析文件。
  - 修复文档。感谢 0xflotus 提供补丁。
  - 代码清理后重新应用绑定参数未替换的修复。感谢 Bernhard J. M. Grun 报告。
  - 添加 `--exclude-db`，生成指定数据库以外的所有报告，可多次指定。

## v10.0 · 2018-09-09 {#v10-0}

这是主要版本，增加新功能，并修复上一版本发布后用户报告的全部问题。

  * 支持 PgBouncer 的 syslog 日志格式。
  * 支持全部 auto_explain 格式：text、xml、json 和 yaml。
  * 支持 `log_line_prefix` 中的 `%q` 占位符。
  * 支持 Michael Paquier 扩展的 jsonlog 格式，使用 `-f jsonlog` 解析。
  * 将 SQL 格式化器替换为 pgFormatter v3.0。

新增命令行选项：

  - 添加 `--prettify-json`，对 JSON 输出进行排版。
  - 添加 `--log-timezone +/-XX`，按相对 GMT 的小时偏移调整日志中的日期/时间后再解析。如果客户端时区不同，仍可能需要通过 `-Z` 调整图表时区。
  - 添加 `--include-time`，直接选择需要展示的时间范围，避免用 `--exclude-time` 逐一排除不需要的范围。
