## v9.2 · 2017-07-27 {#v9-2}

Cette version de pgBadger est une mise à jour de maintenance qui ajoute quelques nouvelles fonctionnalités.

  * Ajouter un rapport de distance entre les points de contrôle et une estimation.
  * Ajouter le support des mots-clés AWS Redshift dans le formateur de code SQL.
  * Ajouter la détection automatique du format du fichier journal en mode distant afin de permettre l'analyse distante du fichier journal de pgbouncer conjointement avec le fichier journal PostgreSQL.

Il existe également quelques corrections de bogues et améliorations de fonctionnalités.

  - Correction du rapport avec histogramme qui n'affichait pas les données supérieures à la dernière plage.
  - Correction de l'analyse de journalctl sans le motif de numéro de ligne ([%l-n]). Remerciements à Christian Schmitt pour le signalement.
  - Ajout du rapport sur la distance et l'estimation du point de contrôle. Remerciements à jjsantam pour la demande de fonctionnalité.
  - Ajout d'informations supplémentaires sur les actions effectuées par le script pour mettre à jour les fichiers CSS et JavaScript, tools/updt_embedded_rsc.pl.
  - Ne plus émettre d'avertissement lorsque tous les fichiers journaux sont vides et quitter avec le code 0.
  - Correction de build_log_line_prefix_regex() qui ne comprenait pas %n comme clé de recherche dans %regex_map. Remerciements à ghosthound pour le correctif.
  - Changement du niveau d'erreur de « FATAL: cannot use CSV » au niveau WARNING. Remerciements à kong1man pour le signalement.
  - Correction de l'avertissement relatif à une valeur non initialisée. Remerciements à Payal pour le signalement.
  - Ajout de « permission denied » à la normalisation des erreurs.
  - Mise à jour de pgBadger vers le dernier commit 5bdc018 de pgFormatter.
  - Ajout du support des mots-clés AWS Redshift. Remerciements à cavanaug pour la demande de fonctionnalité.
  - Correction de l'absence de requête dans le rapport de fichier temporaire lorsque la requête était annulée. Remerciements à Fabrizio de Royes Mello pour le signalement.
  - Normalisation des requêtes avec paramètres liés, remplacés par un « ? ».
  - Vérification de cohérence pour éviter une heure de fin antérieure à l'heure de début. Remerciements à Christophe Courtois pour le correctif.
  - Correction de nombreux mots mal orthographiés et ajustements grammaticaux. Utilisation de « pgBadger » lorsqu'il s'agit du programme et non du fichier binaire. Utilisation d'expressions officielles telles que PgBouncer, GitHub et CSS. Le fichier POD a été synchronisé avec README. Remerciements à Euler Taveira pour le correctif.
  - Correction du menu cassé lors de l'utilisation de --disable-type : le test top_cancelled_info et la fermeture de la liste doivent se trouver à l'intérieur du test disable_type. À cette occasion, mise en retrait du test disable_lock. Remerciements à Euler Taveira pour le correctif.
  - Correction de l'utilisation d'une valeur non initialisée. Remerciements à johnkrugger pour le signalement.
  - Suppression du test de lecture du fichier journal pendant l'auto-détection du format du journal lorsque le fichier est hébergé à distance. Remerciements à clomdd pour le signalement.
  - Ajout de l'auto-détection du format du journal en mode distant pour permettre l'analyse distante du fichier journal de pgbouncer en parallèle avec celui de PostgreSQL.
  - Correction de l'incrémentation erronée du nombre de sessions après la validation de la ligne journal. Remerciements à Achilleas Mantzios pour le signalement.
  - Réorganisation mineure de la description de pgBadger.
  - Correction d'informations redondantes dans la documentation. Remerciements à cscatolini pour le correctif.

## v9.1 · 2017-01-24 {#v9-1}

Cette version de pgBadger est une mise à jour de maintenance qui ajoute quelques nouvelles fonctionnalités.

  * Ajouter un rapport de répartition des classes d'erreur lorsque SQLState est disponible dans log_line_prefix (voir le champ %e).
  * Mettre à jour le formateur SQL pour utiliser le code pgFormatter v1.6.
  * Améliorer la normalisation des messages d'erreur.
  * Ajouter l'option --normalized-only pour générer un fichier texte contenant toutes les requêtes normalisées trouvées dans un journal, avec leur fréquence.
  * Permettre à %c (identifiant de session) de remplacer %p (PID) comme identifiant unique de session.
  * Ajouter les messages d'attente de verrou aux rapports d'événements.
  * Ajouter l'option --start-monday pour faire commencer les semaines du calendrier le lundi au lieu du dimanche par défaut.

Il existe également quelques corrections de bogues et améliorations de fonctionnalités.

  - Ajouter un rapport de répartition des classes d'erreurs lorsque SQLState est disponible dans le préfixe de ligne de journal. Remerciements à jacks33 pour la demande de fonctionnalité.
  - Corriger l'index global incrémental lors du redimensionnement. Remerciements à clomdd pour le rapport.
  - Corriger le champ %i (étiquette de commande) de log_line_prefix pour autoriser le caractère espace.
  - Corriger les options --exclude-line et la suppression du répertoire obsolète lorsque la rétention est activée et que --noreport est utilisé.
  - Corriger une faute de frappe dans « vacuum activity table ». Remerciements à Nicolas Gollet pour le correctif.
  - Corriger le rapport d'autovacuum. Remerciements à Nicolas Gollet pour le correctif.
  - Corriger l'auteur du logo de pgBadger – Damien Cazeils – et l'anglais dans les commentaires. Remerciements à Thibaut Madelaine pour le correctif.
  - Ajouter des informations sur le format de journal de pgbouncer dans l'option -f. Remerciements à clomdd pour le rapport.
  - Ajouter des informations sur --normalized-only dans la documentation.
  - Corriger le rapport cassé de la date-heure introduit dans le correctif précédent.
  - Corriger l'association durée/requête lorsque log_duration=on et log_statement=all. Remerciements à Eric Jensen pour le rapport.
  - Corriger la normalisation des messages concernant les verrous consultatifs (advisory locks). Remerciements à Thibaut Madelaine pour le rapport.
  - Corriger le rapport de sortie d'auto_explain. Remerciements à fch77700 pour le rapport.
  - Corriger la détection automatique du format de journal incorrecte avec les entrées de journal provenant de stdin. Remerciements à Jesus Adolfo Parra pour le rapport.
  - Ajouter une parenthèse ouvrante à la liste des caractères « stop » de la regex utilisée pour rechercher le client base de données dans le préfixe, afin de gérer le format de chaîne du client PostgreSQL incluant le port source. Remerciements à Jon Nelson pour le correctif.
  - Corriger certaines erreurs d'orthographe. Remerciements à Jon Nelson pour le correctif.
  - Permettre à %c (identifiant de session) de remplacer %p (PID) comme identifiant unique de session. Remerciements à Jerryliuk pour le rapport.
  - Permettre à pgBadger de parser le préfixe de journal par défaut qui sera probablement utilisé dans la version 10.0 : '%m [%p] '
  - Corriger la ligne manquante initiale avec l'appel à l'interpréteur.
  - Corriger l'absence des valeurs Moy. dans le rapport CSV. Remerciements à Yosuke Tomita pour le rapport.
  - Corriger le message d'erreur dans la méthode autodetect_format().
  - Ajouter l'option --start-monday pour commencer les semaines du calendrier le lundi au lieu du dimanche par défaut. Remerciements à Joosep Mae pour la demande de fonctionnalité.
  - Corriger l'option --histo-average. Remerciements à Yves Martin pour le rapport.
  - Supprimer la forme plurielle de --ssh-option dans la documentation. Remerciements à mark-a-s pour le rapport.
  - Corriger le filtre --exclude-time et réécrire le code pour ignorer les lignes non souhaitées ainsi que le code mis à jour pour la barre de progression. Remerciements à Michael Chesterton pour le rapport.
  - Corriger la prise en charge du champ %r dans le préfixe au lieu de %h.

## v9.0 · 2016-09-02 {#v9-0}

Cette version majeure de pgBadger est une migration vers Bootstrap 3 ainsi qu'une mise à jour de toutes les ressources (CSS et JavaScript). Elle inclut également la correction de certains bogues et des améliorations de fonctionnalités.

La compatibilité descendante avec les anciens rapports incrémentiels peut être préservée.

  - Les sources et licences des fichiers de ressources sont désormais disponibles dans un sous-répertoire dédié. Un script permettant de mettre à jour la version minifiée intégrée au script pgBadger a été ajouté. Remerciements à Christoph Berg pour son aide et sa demande de fonctionnalité.

  - Essayer de détecter l'utilisateur/base de données/hôte à partir des chaînes de connexion si log_connections est activé et si log_line_prefix ne les inclut pas.
    Extension de l'expression régulière pour détecter automatiquement le nom
    de la base de données, le nom de l'utilisateur, l'adresse IP du client
    et le nom de l'application. Les expressions régulières sont désormais les suivantes :
    
    	db => qr/(?:db|database)=([^,]*)/;
    	user => qr/(?:user|usr)=([^,]*)/;
    	client => qr/(?:client|remote|ip|host)=([^,]*)/;
    	appname => qr/(?:app|application)=([^,]*)/;
    
  - Ajouter la compatibilité descendante avec les versions antérieures de pgBadger en mode incrémentiel en créant un sous-répertoire pour les nouveaux fichiers CSS et JavaScript. Ce sous-répertoire est nommé en fonction du numéro de version majeure de pgBadger.
  - Augmenter la taille du logo pgBadger qui apparaît trop petit avec la nouvelle taille de police.

  - Normaliser les informations détaillées dans tous les rapports.

  - Corriger l’icône de copie en double dans le rapport des verrous.

  - Corriger le graphique manquant dans l'histogramme du temps de session. Remerciements à Guillaume Lelarge pour le rapport.

  - Ajouter un fichier LICENSE indiquant les licences utilisées par les fichiers de ressources. Remerciements à Christoph Berg pour le correctif.

  - Ajouter un correctif à la bibliothèque jqplot pour corriger une boucle infinie lors de la tentative de téléchargement de certains graphiques. Merci à Julien Tachoires pour son aide dans la résolution de ce problème.
  - Le script tools/updt_embedded_rsc.pl appliquera le correctif au fichier de ressources resources/jquery.jqplot.js et ne produira pas d'alerte s'il a déjà été appliqué.

  - Supprimer la virgule finale unique à la fin du jeu de données du graphique camembert. Merci à Julien Tachoires pour le rapport.

  - Modifier l'affichage de l'erreur normalisée

  - Supprimer les fichiers inutilisés ou générés automatiquement

  - Mettre à jour tous les fichiers de ressources (js+css) et créer un répertoire pour inclure les sources des bibliothèques JavaScript utilisées par pgBadger. Un nouveau script, tools/updt_embedded_rsc.pl, peut être utilisé pour générer la version minifiée de ces fichiers et les intégrer directement dans pgBadger. Ce script intègre également le fichier de police open truetype FontAwesome.otf dans le fichier fontawesome.css.
