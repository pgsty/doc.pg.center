Здесь полностью сохранена история изменений pgBadger 13.x из исходного проекта, от новых версий к старым.

## v13.2 · 2025-12-29 {#v13-2}

Это выпуск pgBadger с исправлениями проблем и патчами,
предложенные пользователями после предыдущего выпуска.

  - Исправлена нормализация, некорректно обрабатывавшая сбалансированные строки
    в одинарных кавычках с экранированными кавычками внутри. Спасибо Bertrand
    Bourgier за сообщение.
  - Исправлены требования к заполнителям в документации.
  - Исправлен случай, когда примеры строк журнала с ошибками не попадали в отчёт.
    Спасибо john doe за сообщение.
  - Исправлена возможная проблема приоритета между ! и %s. Спасибо Luca
    Santarelli и Philipp Trulson за сообщение.
  - Код pgFormatter обновлён до версии 5.9.
  - Добавлено действие GitHub CI для тестирования при отправке коммитов.
  - Исправлен разбор заполнителя %r в log_line_prefix. Спасибо nike7o0 за
    сообщение.
  - Исправлено предупреждение о неинициализированном значении. Спасибо Ales
    Zeleny за сообщение.
  - Документация по параметрам SSH для разбора журналов Postgres дополнена
    примерами. Спасибо Ulrich Konrad за патч.
  - Добавлена команда --ssh-sudo для запуска команд по SSH через sudo. Спасибо
    Andrew Jackson за патч.
  - Исправлена возможная проблема приоритета между ! и строковым eq. Спасибо
    Adrien Nayrat за сообщение.
  - Исправлен разбор статистики pgbouncer. Спасибо mrgtt за сообщение.

## v13.1 · 2025-03-16 {#v13-1}

Это выпуск pgBadger с исправлениями проблем, о которых
пользователи сообщили после предыдущего выпуска, и добавляет новые возможности:

  - Добавлен новый отчёт о пропускной способности vacuum с диаграммой vacuum
    по таблицам, потребляющим больше всего процессорного времени. В таблице
    показано время ввода-вывода для чтения и записи по каждой таблице, а также
    затраченное на таблицу процессорное время. Спасибо Ales Zeleny за запрос
    функции. Этот патч также добавляет замороженные страницы и кортежи в отчёт
    Vacuums per Table.
  - Добавлен параметр --no-fork, полностью отключающий создание дочерних
    процессов при отладке. Спасибо Ales Zeleny за запрос функции.
  - В необработанный вывод CSV добавлены миллисекунды. Спасибо Henrietta
    Dombrovskaya за запрос функции.
  - При обработке нескольких файлов в примеры отчётов добавлено имя файла
    журнала. Спасибо Adrien Nayrat за запрос функции.

Полный список изменений и благодарностей:

  - Исправлен разбор параметров привязки. Спасибо Thomas Kotzian за патч.
  - Фильтр запросов применяется к многострочным запросам. Спасибо Benjamin
    Jacobs за патч.
  - Обновлён результат теста с учётом изменений в хранении имени файла журнала.
  - Исправлено различие уровней сообщений ERROR и LOG в выводе JSON. Спасибо
    Philippe Viegas за сообщение.
  - Удалён импорт неэкспортируемого метода tmpdir из File::Temp. Спасибо
    kmoradha за сообщение.

## v13.0 · 2024-12-08 {#v13-0}

Это основной выпуск pgBadger, исправляющий проблемы, о которых пользователи
сообщили после предыдущего выпуска, и добавляющий новые возможности:

  * Добавлены два новых параметра для переопределения границ гистограмм
    запросов и сеансов.
       --histogram-query VAL   : use custom inbound for query times histogram.
                                 Default inbound in milliseconds:
                             0,1,5,10,25,50,100,500,1000,10000
       --histogram-session VAL : use custom inbound for session times histogram.
                                 Default inbound in milliseconds:
                             0,500,1000,30000,60000,600000,1800000,3600000,28800000
    Спасибо JosefMachytkaNetApp за запрос функции.
  * Добавлена поддержка плана auto_explain для журналов форматов csv и json.
    Спасибо zxwsbg и Alexander Rumyantsev за сообщение.
  * В события добавлены три ранее не учитывавшихся сообщения LOG: unexpected
    EOF, incomplete startup packet и detected deadlock while waiting for.
    Спасибо dottle за сообщение.

Проблемы обратной совместимости:

  - Изменён способ хранения событий уровня LOG, отображаемых в отчётах Events.
    Некоторые из них по-прежнему отображались и учитывались как ошибки, а не
    как записи уровня LOG. Теперь они хранятся и отображаются как EVENTLOG,
    что отличает их от запросов. Это изменение нарушает обратную совместимость
    при использовании pgbadger в инкрементальном режиме: смешанное поведение
    будет наблюдаться только в течение недели обновления. Спасибо Matti
    Linnanvuori за сообщение.

Исправления ошибок:

  - Исправлено отсутствие запросов, приводящих к наибольшему числу отмен из-за statement_timeout.
  - Обновлены регрессионные тесты.
  - Исправлено форматирование плана explain, извлечённого из журнала формата csv.
  - Исправлено отсутствие данных autovacuum из jsonlog в отчётах Average
    Autovacuum Duration, Tuples removed per table и почасовых vacuum в отчёте
    об активности autovacuum. Спасибо Ales Zeleny за патч.
  - Исправлена непривязанная строка, которая не сопоставлялась с затратными по
    времени запросами привязки. Спасибо Henrietta Dombrovskaya за сообщение.
    Исправлено использование неинициализированного значения при сопоставлении
    с шаблоном. Спасибо Junior Dias за патч.
  - Параметр --csv-separator применяется к необработанному экспорту CSV.
    Разделитель по умолчанию — точка с запятой (;). Спасибо Henrietta
    Dombrovskaya за запрос функции.
  - В необработанном выводе csv пустые параметры и имя приложения больше не
    заключаются в двойные кавычки.
  - Запросы, содержащие точку с запятой, заключаются в двойные кавычки в
    необработанном выводе csv. Спасибо Henrietta Dombrovskaya за сообщение.
