Данный документ описывает версии, поддерживаемые проектом etcd.

## Версионирование сервиса и поддерживаемые версии {#service-versioning-and-supported-versions}

Версии etcd выражаются как **x.y.z**, где **x** — мажорная версия, **y** — минорная версия, а **z** — версия исправления, в соответствии с терминологией [Semantic Versioning](https://semver.org/).  
Новые минорные версии могут добавлять дополнительные функции в API.

Проект etcd поддерживает ветки релизов для текущей версии и предыдущего выпуска. Например, когда v3.5 является текущей версией, поддерживается v3.4. Когда выпускается v3.6, v3.4 прекращает поддержку.

Исправления, включая исправления уязвимостей, могут быть перенесены в эти два ветвления выпусков в зависимости от серьезности и реализуемости. Патч-релизы выпускаются из этих ветвлений по мере необходимости.

Команда разработчиков [Maintainers](https://github.com/etcd-io/etcd/blob/main/OWNERS) несёт ответственность за это решение.

Вы можете проверить версию работающего кластера etcd с помощью `etcdctl`:

```sh
etcdctl --endpoints=127.0.0.1:2379 endpoint status
```

## API версионирование {#api-versioning}

Ответы `v3` API не должны изменяться после выпуска 3.0.0, но со временем будут добавляться новые функции.
