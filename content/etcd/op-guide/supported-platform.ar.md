## مستويات الدعم {#support-tiers}

يعمل etcd على منصات مختلفة، لكن الضمانات التي يقدمها تتوقف على مستوى
دعم المنصة:

- **المستوى 1**: مدعوم بالكامل من [مشرفي etcd][etcd maintainers]؛ ومضمون أن يجتاز etcd
  جميع الاختبارات بما فيها الاختبارات الوظيفية واختبارات المتانة.
- **المستوى 2**: مضمون أن يجتاز etcd اختبارات التكامل والاختبارات الشاملة من البداية إلى النهاية، لكن
  ليس بالضرورة الاختبارات الوظيفية أو اختبارات المتانة.
- **المستوى 3**: مضمون أن يُبنى etcd، وقد يُختبر اختبارًا خفيفًا (أو لا يُختبر)،
  ولذلك ينبغي اعتباره _غير مستقر_.

## الدعم الحالي {#current-support}

يسرد الجدول التالي المنصات المدعومة حاليًا ومستوى دعم etcd المقابل
لكل منها:

| المعمارية | نظام التشغيل | مستوى الدعم |       المشرفون        |
|:------------:|:----------------:|:------------:|:--------------------:|
| AMD64        | Linux            |      1       | [مشرفو etcd][etcd maintainers] |
| ARM64        | Linux            |      1       | [مشرفو etcd][etcd maintainers] |
| AMD64        | Darwin           |      3       |                      |
| ARM64        | Darwin           |      3       |                      |
| AMD64        | Windows          |      3       |                      |
| ppc64le      | Linux            |      3       |                      |
| s390x        | Linux            |      3       |                      |

المنصات غير المدرجة غير مدعومة.

## دعم منصة جديدة {#supporting-a-new-platform}

ترغب في المساهمة في etcd بوصفك «المشرف الرسمي» لمنصة جديدة؟ إضافة
إلى الالتزام بدعم المنصة، عليك إعداد التكامل المستمر (CI) الخاص بـ etcd بحيث يفي
بالمتطلبات التالية، تبعًا لمستوى
الدعم:

| التكامل المستمر لـ etcd               | المستوى 1 | المستوى 2 | المستوى 3 |
|---------------------------------------|:-------:|:-------:|:-------:|
| نجاح البناء                            | &check; | &check; | &check; |
| نجاح اختبارات الوحدات                  | &check; | &check; |         |
| نجاح اختبارات التكامل والاختبارات الشاملة | &check; | &check; |         |
| نجاح اختبارات المتانة                  | &check; |         |         |

لمثال على إعداد CI من المستوى 2 لمعمارية ARM64، راجع [طلب السحب etcd PR #12928][etcd PR #12928].

## المنصات غير المدعومة {#unsupported-platforms}

لتجنب تشغيل خادم etcd دون قصد على منصة غير مدعومة، يطبع etcd
رسالة تحذير ويخرج فورًا إلا إذا كان متغير البيئة
`ETCD_UNSUPPORTED_ARCH` مضبوطًا على المعمارية المستهدفة.

> [!WARNING]
> **الأنظمة ذات 32 بت**
>   لدى etcd **مشكلات معروفة** على الأنظمة ذات 32 بت بسبب خطأ في بيئة تشغيل Go.
>   لمزيد من المعلومات، راجع [قضية Go رقم #599][go-issue] و[ملاحظة خطأ
>   حزمة atomic][go-atomic].
>
>   [go-atomic]: https://golang.org/pkg/sync/atomic/#pkg-note-BUG
>   [go-issue]: https://github.com/golang/go/issues/599
