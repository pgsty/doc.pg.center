## Ограничение размера запроса {#request-size-limit}

etcd разработан для обработки небольших пар «ключ — значение», характерных для метаданных. Более крупные запросы будут работать, но могут увеличить задержку других запросов. По умолчанию максимальный размер любого запроса составляет 1.5 MiB. Этот лимит можно настроить с помощью флага `--max-request-bytes` для сервера etcd.

## Ограничение размера хранилища {#storage-size-limit}

По умолчанию размер хранилища ограничен 2 GiB. Это ограничение настраивается с помощью флага `--quota-backend-bytes`. 8 GiB — рекомендуемый максимальный размер для обычных сред, etcd выдаёт предупреждение при запуске, если сконфигурированное значение превышает его.
