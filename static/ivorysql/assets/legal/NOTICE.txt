## Adaptations

AsciiDoc has been converted to Markdown. Navigation and URLs have been reorganized;
version attributes use the values in each language's antora.yml; code fences,
anchors, links and table rendering have been repaired. Original image bytes are
stored under content hashes. Each inherited page identifies its exact source and
is marked upstream_modified: true. No language has been filled with a new machine
translation. Historical versions, limitations, examples and plans remain as stated
by the upstream text; source inconsistencies are not silently updated.

The merged-site migration manifest is data/imports/ivorysql.json. The source
revision is recorded in data/upstreams.yaml. Two empty 4.7.adoc files are excluded. Two screenshot
references in the Chinese PostgreSQL parameter reference do not exist in the
pinned source tree; their positions retain a notice and link to the source page.

OINK is pinned to v1.5.1 and retains its own Apache-2.0 licence and bundled-asset
notices. Collection icons are navigation symbols, not IvorySQL trademarks.
